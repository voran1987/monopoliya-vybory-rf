# Монополия: выборы в России

Учебная игра в стиле «Монополии» по теме «Избирательная система РФ». Ведущий держит главный экран (например, на проекторе), каждая команда играет со своего смартфона, остальные студенты смотрят.

Адрес игры: https://voran1987.github.io/monopoliya-vybory-rf/

## Как это устроено

- `index.html` — вся игра в одном файле.
- `firebase-config.js` — подключение к Firebase Realtime Database (проект `election`).
- `database.rules.json` — правила доступа для консоли Firebase.

Состояние игры считает страница ведущего и записывает в базу. Команды отправляют в базу только свои действия (бросок, ответ, продажа, обмен), страница ведущего их проверяет и выполняет. Страница ведущего должна быть открыта всё время игры. Ключи в базе удаляются сразу после записи, поэтому прочитать их из базы нельзя.

Пока Firebase не подключён, игра работает в локальном режиме на одном устройстве.

## Один раз: настроить базу

1. Realtime Database → Rules: вставьте содержимое `database.rules.json` → Publish.
2. Realtime Database → Data: добавьте в корень узлы (имена строго маленькими буквами):
   - `secret` — ключ ведущего;
   - `team1`, `team2`, `team3` (при игре на четыре команды ещё `team4`) — по одному ключу на команду.
   Ключи придумайте разные, по 12–16 символов из букв и цифр.

## Что делает команда на телефоне

В свой ход: бросает кубики, отвечает на вопросы, отказывается от покупки, передаёт ход. В любой момент: продаёт округа банку и предлагает обмен другой команде. Партнёр принимает или отклоняет предложение на своём телефоне. Ведущий может сделать всё то же на своём экране за любую команду.

После перезагрузки страницы ведущего партия восстанавливается из базы, открытый вопрос закрывается. «Начать заново» сбрасывает партию у всех.

## Правила игры

- Играют 2–4 команды, у каждой 15 мандатов, поле из 40 клеток.
- Чтобы занять округ, нужно верно ответить на вопрос с четырьмя вариантами. После ошибки верный вариант и справка не показываются.
- Аренда на чужом округе — половина цены, ×2, если у владельца вся цветная группа.
- Округа можно продать банку (половина цены) и обменять между командами вместе с мандатами.
- «Шанс» — вопросы с наградой +2, «Казна» — события со штрафами и бонусами, проход через старт +2.
- «Подвести итоги»: мандаты плюс стоимость занятых округов.
