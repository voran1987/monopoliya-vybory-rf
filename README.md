# Монополия: выборы в России

Учебная игра в стиле «Монополии» по теме «Избирательная система РФ». Ведущий ведёт игру на одном экране, студенты на смартфонах видят поле, вопросы и счёт в реальном времени.

Адрес игры: https://voran1987.github.io/monopoliya-vybory-rf/

## Как это устроено

- `index.html` — вся игра в одном файле.
- `firebase-config.js` — подключение к Firebase Realtime Database (проект `election`).
- `database.rules.json` — правила доступа для консоли Firebase: читать состояние может любой, писать только тот, кто знает ключ ведущего.

Пока Firebase не подключён, игра работает в локальном режиме на одном устройстве, без синхронизации.

## Один раз: обновить правила базы

В консоли Firebase: Realtime Database → Rules → вставьте содержимое `database.rules.json` (узлы `secret` и `monopoly`) → Publish. Затем в Data создайте узел `secret` со значением вашего ключа ведущего (имя строго маленькими буквами).

## Как пользоваться

- Ведущий один раз открывает `https://voran1987.github.io/monopoliya-vybory-rf/?key=ВАШ_КЛЮЧ` (значение узла `secret`). Ключ запоминается в браузере, из адреса убирается. Вверху надпись «Ведущий: синхронизация включена».
- Студенты открывают `https://voran1987.github.io/monopoliya-vybory-rf/` без ключа: надпись «Просмотр», кнопок управления нет.
- Если у ведущего написано «Не сохранено: проверьте ключ ведущего», ключ в ссылке не совпадает со значением `secret` в базе.
- После перезагрузки страницы ведущего партия восстанавливается из базы. Вопрос, который был открыт в момент перезагрузки, закрывается.
- «Начать заново» сбрасывает партию у всех.

## Правила игры

- Играют 2–4 команды, у каждой 12 мандатов. Команды ходят по полю из 40 клеток.
- Чтобы занять округ, нужно верно ответить на вопрос с четырьмя вариантами. После ошибки верный вариант и справка не показываются.
- Аренда на чужом округе — половина цены, ×2, если у владельца вся цветная группа.
- Округа можно продать банку (половина цены) и обменять между командами вместе с мандатами.
- «Шанс» — вопросы с наградой +2, «Казна» — события со штрафами и бонусами, проход через старт +2.
- «Подвести итоги»: мандаты плюс стоимость занятых округов.
