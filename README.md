# Монополия: выборы в России

Учебная игра в стиле «Монополии» по теме «Избирательная система РФ». Один HTML-файл, без сборки и серверной части.

## Как играть

- Открыть `index.html` в браузере или перейти по ссылке GitHub Pages.
- Команды (2–4) бросают кубики и ходят по полю из 40 клеток.
- Чтобы занять округ, нужно верно ответить на вопрос с четырьмя вариантами. Верный ответ и справка после ошибки не показываются.
- Попадание на чужой округ: аренда в половину цены, удвоенная, если у владельца вся цветная группа.
- Округа можно продать банку (половина цены) и обменять между командами вместе с мандатами.
- «Шанс» — вопросы с наградой, «Казна» — события со штрафами и бонусами.
- Кнопка «Подвести итоги» считает мандаты плюс стоимость округов.

## Файлы

- `index.html` — игра целиком (стили, данные вопросов и логика).

Шрифты подключаются с Google Fonts. Без интернета игра работает с системными шрифтами.
